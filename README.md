# PIBIT - Inicação Tecnológica

## Captura de dados sobre inovação tecnológica para desenvolvimento social sustentável

**Objetivo**: Desenvolver um protótipo para automação na captura de dados de patentes de invenção no repositório Google Patents por meio de técnicas de web scrapping.


**Etapas do processo**:

1) Compreender a estrutura de um documento patentário e identificar dados a serem extraídos;

2) Analisar técnicas, algoritmos e bibliotecas para raspagem de dados;

3) Desenvolver e testar versão do protótipo que selecione patentes por diferentes critérios de busca (ex: período, palavras-chave, IPC ou titular) e exporte os dados das patentes em arquivo estruturado (csv, xlsx, json, txt);

4) Realizar testes para estabelecer limitações de capacidade e performance estimadas para o protótipo;

5) Gerar documentação e disponibilizar os códigos

Captura de dados do [Google Patents](https://patents.google.com/).
